# Working on contractor

- Game content (NPCs, contracts, items, world reactions) goes into content packs: read CONTENT.md first.
  `python3 tools/content.py ref` lists what exists; `./content_check.sh <pack>` regenerates and checks a pack.
- Design rules for content are the pillars in README.md: several solutions per problem, reactions in the world, no dead ends.
- Don't hand-edit files a pack generated (they start with "# Generated by content/..."). Change the pack and rerun it.
- Playtests: `contractor autoplay -headless <name>`; trace an actor with `AUTOPLAY_TRACE=<name>` (or `player`).
- Before committing engine changes: `go test ./game -run 'ChapterMaps|Chapters|StarterQuest'` and the affected playtests.
